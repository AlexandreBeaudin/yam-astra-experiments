# Bundled fonts

Variable Latin WOFF2 assets from Fontsource packages, version 5.2.8:

- `@fontsource-variable/inter/files/inter-latin-wght-normal.woff2`
- `@fontsource-variable/jetbrains-mono/files/jetbrains-mono-latin-wght-normal.woff2`

Downloaded from the version-pinned npm packages via jsDelivr. Corresponding
package LICENSE files are included alongside the fonts. No runtime network
requests are needed. Inter supports UI weights 400, 500, 600; JetBrains Mono
supports telemetry weights 400, 500 through variable font weight axes.
