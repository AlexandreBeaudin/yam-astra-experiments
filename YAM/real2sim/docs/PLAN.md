# 实施计划

## 目标与范围

将真实 episode 转成可复现的场景包、时间轴和多视角对比报告，首先用 Xtrainer 叠杯任务做样板。
候选 episode 为 `20260912135045`，任务数据已存在；完整清晰度和任务片段仍待审核。
默认先做视觉回放，之后才判断是否具备接触/动作回放的数据条件。

仅有 RGB、关节状态和相机标定，通常不能唯一确定遮挡表面、道具轨迹、质量、摩擦与控制延迟。
模型辅助建模提供可执行的几何假设；绝对尺寸靠测量/标尺/已知几何，多视角和留出帧负责验证。

## 阶段与交付

| 阶段 | 工作 | 交付物 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| M0 输入审计 | 帧完整性、时间语义、标定有效性、模型路径、任务关键帧 | episode 清单、缺口清单、三视角关键帧 | 已明确每个字段来源；机器人模型可获得；允许的标定误差有记录 |
| M1 统一表示 | 数据适配、命名关节、相机帧图、动作与状态分离 | 标准 episode、平台描述、变换单元检查 | 能输出多个时刻的 FK；与控制器/参考 FK 对比通过 |
| M2 后端试验 | 优先官方 Isaac Lab 环境与 USD，导入本机相机和 50 帧；必要时对比 MuJoCo | 加载、投影、速度/误差/成本报告、选型记录 | 本机 GPU/版本验证通过；FK 与投影正确；确认主后端 |
| M3 道具与布局 | 测尺寸、关键帧、多视角配准、参数化资产、材质和碰撞体 | 版本化资产包、静态场景、证据记录 | 独立视角/帧验证几何；杯口保持空心；桌面尺度正确 |
| M4 视觉回放 | 状态回放、腕部相机跟随、物体跟踪/人工关键帧、统一渲染 | 三视角 real/sim 并排视频、遮罩叠加、JSON 指标 | 满足暂定视觉指标，标明物体轨迹来源和可见度 |
| M5 接触回放 | 夹爪映射、执行器跟踪、质量摩擦和接触参数辨识 | 物体自由运动的任务回放、失败分析 | 不强制设定物体轨迹，留出 episode 上接触事件及任务结果合理 |

暂不承诺日程：M0/M2 完成后依据模型可用性、硬件和目标档位估算。每阶段可单独交付。
初期只实现一个完整后端；有官方环境后优先复用，仅在不满足目标或部署条件时试验另一后端。

## 回放模式必须明确

- `visual_state`：按实测关节状态设定机器人；道具按估计轨迹设定。它能验证视觉重建，不能验证抓取物理。
- `contact_trajectory`：机器人以执行器跟踪参考轨迹，道具只给初态并由物理解算；记录实际跟踪误差。
- `dynamic_action`：重放记录动作，经明确的控制器、限速和延迟模型驱动。动作若只是位置目标，不能称为力矩回放。
- 混合方式（例如抓取阶段将物体焊接到夹爪）必须逐段标注，不能计为自然接触成功。

## 配准与优化顺序

1. 锁定单位、关节名称/正负号、模型基座/法兰定义和图像方向。
2. 估计图像与关节的时间偏移，保留不确定度；缺硬件时间戳时不声称精确同步。
3. 用已知机器人几何验证相机与基座；原始标定不可覆盖，调整另存 delta。
4. 固定世界尺度与基准坐标后，求桌面、物体初态和轨迹。
5. 先优化轮廓、关键点与遮挡，再优化材质、灯光与背景。
6. 进入物理档后才辨识质量、摩擦、接触与控制参数，并在独立 episode 上评估。

优化要使用有界参数及标定先验。禁止让逐帧相机外参自由漂移来掩盖时间错位或机器人模型错误。
top 方法腕部外参与基座外参存在关联，原数据上的闭环一致性不等于独立精度证明。

## 暂定验收指标（待 M0 基线后冻结，不是当前实测结果）

在原始 640×480 图像上；其他分辨率按图像尺寸比例缩放像素阈值。

| 项目 | 第一版目标 | 计算/限制 |
| --- | --- | --- |
| 输入完整性 | 所选评估帧均有各路图像及状态，或明确排除 | 输出缺帧、重复帧、时间假设；不得静默丢弃 |
| 静态几何投影 | 已知机器人/标定板关键点中位误差 ≤ 5 px，P95 ≤ 15 px | 每个相机单列；只在有可靠可见标注的点上计算 |
| 动态投影 | 可见指尖/道具关键点中位误差 ≤ 10 px，P95 ≤ 25 px | 分动作阶段报告，另报跟踪有效覆盖率，避免只挑静止帧 |
| 道具轮廓 | 各相机可见区域平均 mask IoU ≥ 0.80 | 说明遮挡处理；小目标同时报告像素轮廓误差 |
| 留出集 | 时间连续分段留出约 20%，另保留一个 episode | 参数拟合不得使用留出片段；只有一条数据时标记泛化未验证 |
| 外观 | 三路并排/叠加视频人工复核；SSIM/感知指标辅助 | 不允许背景相似度淹没机器人和道具区域误差 |
| 物理阶段 | 报告抓取/释放时刻、滑动、穿透、物体 6D 轨迹与任务结果 | 阈值在物体轨迹标注与任务定义具备后冻结；无参考时写 unavailable |

旋转对称杯子的轴向旋转应按对称性评估；遮挡阶段保留轨迹多解和低置信标记。
基座/相机移动、相机内参或图像预处理变更后，场景版本应失效并重新验证。

## 下一轮具体任务

1. 获取官方 USD 及全部依赖，记录资产版本/许可；核对关节、法兰与本机安装。已有 STEP 仅作为核对/修补来源。
2. 实现 Xtrainer 数据审计与标准化，重点核对真实时间和夹爪字段。
3. 抽取初始、接近、抓取、搬运、放置、结束关键帧；量杯口/杯底直径、高度、壁厚和桌面高度。
4. 在可用 GPU 主机上做后端试验，确认第一版目标档位并选择主后端。
5. 先交付一个短片段的三路回放，再扩大到整条任务与其他平台。
