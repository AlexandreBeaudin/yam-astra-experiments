## 分布设计

先固定角色：左臂拿杵并交接，右臂接杵和捣压。不要像击球任务那样随机交换执行臂。研钵开口朝上，研杵横放，粘土保持中央单球。

当前坐标均为已有 Xtrainer 场景参考系、单位米，桌面 Z=0.063：

| 因子 | 范围 | 采样方式 |
|---|---|---|
| 研钵 X | -0.34 ～ -0.07 | 三档：[-0.34,-0.25]、[-0.25,-0.16]、[-0.16,-0.07] |
| 研钵 Y | -0.79 ～ -0.64 | 连续随机，右臂侧 |
| 研杵中心 X | -0.34 ～ -0.09 | 连续随机 |
| 研杵中心 Y | -0.43 ～ -0.32 | 连续随机，左臂侧 |
| 研杵轴向角 | -60° ～ +60° | 三档：[-60,-20]、[-20,20]、[20,60]；由 +X 朝 +Y 为正 |
| 粘土位置与直径 | 碗中央，30 mm | 固定假设，暂不加入形状/尺寸随机化 |

主分层是研钵 X 三档 × 研杵朝向三档，共九箱。训练 100 条，每箱 11–12；验证 30 条，每箱 3–4。两组使用相同参数域和独立种子，全部九箱均覆盖，分箱 TV=0.06。没有完全重复或近重复布局；近重复标准沿用共同策略（对应物体 XY 均小于15 mm且朝向差小于8°）。

这是一套有边界的同域验证分布，不是对全部桌面、任意杵朝向或任意粘土形状的覆盖。后续真实试采应按分箱核对成功率与摆放误差，再决定是否扩大范围。所有重复录制应继承原布局的 train/validation 和 split_group_id，不能再按帧随机分组。

## 检查范围

130 条全部通过：完整 STL 顶点的桌面边界、标定主相机视锥、研钵/研杵保守包络间隙至少70 mm；每条左臂取物/接近/抬升和右臂碗上方/回撤的五个固定向下手掌工作空间代理 IK，共650次。交接区域另做左右臂各一个独立代理 IK。

代理 IK 沿用现有估计的手掌到抓取点距离165.7 mm，不代表已识别研杵的真实抓取变换。共享交接点分别可达，也不代表两只夹爪能同时无碰撞抓住它。未验证：夹爪开口/夹持力、实际横杵抓取姿态、双臂交接路径、横杵滚动稳定性、摩擦、碗的固定以及粘土变形动力学。因此本批状态是任务分布审阅草稿，不能表述为真实任务仿真验收通过。

场景预览使用 Isaac Sim 5.1.0 / Python3.11 / PhysX 统一环境，但不运行物理步进。新任务渲染采用 PathTracing 32 spp，避免批量瞬移物体时实时渲染的历史残影；不会修改 task1 的渲染器或已发布图像。所有图片对照当前布局和标定的哈希；主相机还检查分割像素是否落在独立计算的 STL 投影包络内。
