2. 核对训练100、验证30，查看代表及边界布局的主相机/全环境预览。当前仍是工作空间代理 IK，不是实际夹持/双臂交接无碰撞验收。
3. 点击“发布所选版本供下次采集使用”。等待“已发布；下次选择该任务采集时自动加载”。该任务的版本状态也应显示“已发布”。


- 终端二：再次运行 collect.sh，选3，再选择 TASK-X-0003（当前任务菜单的2）。
- 按启动器提示确认当前 top 相机安装、图像方向和桌面仍对应已有标定。
- 自动打开 http://127.0.0.1:8770/ 。确认标题为 TASK-X-0003，能看到实时主视角和各自独立的左/右腕视角。

## 现场试采顺序

1. 勾选实时页“现场试采模式”。候选缩为12条训练布局：覆盖九个分箱，再补研杵朝向及研钵X边界。验证集不参与调试。
2. 先用一条布局核对投影：研钵外径约130mm、研杵长110mm，研杵横放，粘土暂为约30mm单球、放在碗中央。若整体投影都错位，先核对相机/桌面/图像方向，不通过挪动布局参数掩盖标定偏差。
3. 先遥操接近，确认真实夹爪能够夹持，再尝试抬升、交接、右臂拿正和捣压。这里没有自动执行运动，操作员沿用原按钮与遥操控制。
4. 按原按钮开始/结束录制。结束后手动还原、点击下一条指引、重新摆放，再录制；不重启 collect。
5. 每条记录在现场核对表中填写轨迹目录、投影对齐、抓取、交接、操作空间及问题。困难布局可以重复试采；保留失败原因，不把它计为通过。
6. 完成代表/边界试采并修正问题后，取消试采模式，开始正式采集。该动作会选择正式列表第一条；录制前核对屏幕中的布局编号。正式验证布局也可以从下拉列表选取。

切换布局/模式均只作用于下一次录制。当前正在录制的轨迹保留开始时的投影、布局、分组和 capture_phase。

试采记录：`placement_guidance.json` 的 `guidance.capture_phase = "field_test"`；正式为 `"collection"`。试采不计入实时页的正式覆盖统计。它们都保留原 train/validation 和 split_group_id；训练导出时应显式过滤试采阶段，不能只按 train 标签把调试记录全部并入训练。本次未更改原 HDF5 转换器。

## 每条轨迹核对文件

- placement_guidance.json：任务、布局、分组、阶段、投影哈希和录制关联。
- guidance_projection.png：开始录制时固定的透明投影。
- guidance_overlay_first_frame.jpg：该投影与保存的第一帧叠加。

正式覆盖统计反映保存了哪些指导目标，不代表实际摆放已自动核对通过。现场表位于 `runs/task_x_0003_train100_val30_20260923/field_test_checklist.csv`，已列出12条目标、分组和参数，检查结果留空供填写。
