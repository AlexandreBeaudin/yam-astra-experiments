# Isaac Sim 5.1 升级验收报告 · 2026-09-15

**结论：本机离线 real2sim2real 软件回归通过，32 个阶段全部通过。**
统一环境为 Isaac Sim 5.1.0（wheel 版本 5.1.0.0）、Python 3.11.16、PhysX。
本机 Ubuntu 22.04.5 / RTX 4090 24 GB / NVIDIA 580.178.04。
这不代表纸杯完整抓放/叠杯成功，也不代表已经完成本次升级后的真机现场验收。

## 兼容修复

- 新建 `.runtime/isaacsim-5.1`，保留原工具环境与4.5对照，数采环境未更改。
- 按SDK要求固定NumPy 1.26.0、trimesh 4.5.1、imageio 2.37.0等142个包；依赖检查通过。
- 统一启动脚本清理继承的Python路径，检查SDK/Python版本；实际验证4.5在Kit启动前被拒绝。
- 所有仿真入口写入真实运行版本，移除固定“4.5”输出标记。
- 语义分割迁移到5.1的 `add_labels`，实测投影和遮挡过滤通过。
- 完整扩展清理曾在接触回放结束后发生原生段错误。正常完成使用Kit默认快速退出；异常时先打印并刷新堆栈，再以非零状态结束独立子进程，避免原生清理掩盖失败；故意抛异常测试返回1，重跑接触流程正常退出。
- 修正视觉回放视频和网页播放间隔随抽帧步长计算，避免全帧测试仍用旧的6fps展示速度。原始24Hz仍是历史假设，不宣称已验证采集时序。
- 安装脚本支持YAM已有系统uv，重复安装没有改变已锁定的环境。
