Kp controls the response to position error; Kd supplies velocity damping. The
larger Kp values request stronger tracking of the same joint targets. GPT's target
choices and the Astra runner's trajectory limits are separate and unchanged by
this configuration update. This change therefore does not by itself establish
that GPT will request larger movements or solve early stopping.

Validation is offline only: check the runtime configuration loaders and follower
arm selection without opening CAN or moving hardware. Physical tracking with
these gains remains unverified; confirm the gains in fresh diagnostics after a
normal restart.

## Larger-motion experiment update

Kd `[6,6,6,1.8,1.8,1.8]`, and gripper Kp/Kd `30/1.8`.

motor torque limits, and does not guarantee that small commands overcome friction.
