# 两批 YAM 成功数据的初始摆放分布（2026-09-15）

## 范围与结论

本次按「实际录制首帧中的初始摆放分布」分析 TASK-YAM-0004 和 TASK-YAM-0006，各 100 条成功 MCAP。共提取 200 张主相机首帧、600 个物体位置估计；没有从飞书物料数量反推场景物体数量。

两批数据都有摆放变化，但存在明显的空间偏向：香肠集中在箱子两侧，小方块绝大多数在凹槽右侧。不能把这些观察直接解释为整个工作区的均匀覆盖或模型泛化能力。

### TASK-YAM-0004：香肠入泡沫箱

- 100 张首帧每张可见 1 个箱子、3 根香肠。
- 相对箱体中心，56 条为画面左 1 根、右 2 根；44 条为左 2 根、右 1 根。
- 300 根香肠中，144 根在箱体画面左侧，156 根在右侧；形成两个明显的位置簇。
- 香肠长轴主要沿画面上下方向。相对画面竖直方向的角度 P5/P50/P95 约为 −36°/−5°/+29°，按 180° 对称处理。角度是图像投影方向，不是桌面世界坐标 yaw。
- 箱体中心估计的 x、y 各自 P5–P95 为 x≈285–356、y≈191–255 像素。箱体边缘受反光影响，此值仅作粗略空间集中程度参考，不用于精确位姿或尺寸验收。
- 香肠到箱体图像中心的距离 P5/P50/P95 约 112/156/214 像素，同样受到箱体中心估计偏差影响。

## 提取方法和局限

1. 使用原采集解释器读取 MCAP summary/quality，并解码每条实际第一张 main RGB；保留源时间戳和录制文件路径。
2. 在 640×480 原图上按颜色与轮廓提取绿色方块/底座、香肠和箱体；位置使用最小包围矩形中心。
3. 查看首帧和检测拼图。香肠 episode_0039、0040、0042 的贴近目标及 0082、0083 的漏检，共 8 根目标用人工端点估计补充；不是精密标点，单独记录 `manual_endpoint_estimate`。
4. 箱体保留 `coarse_reflection_sensitive_estimate` 标签；反光会使边界偏大。其定位精度尚无独立人工标注集验收。其他自动检测也属于图像平面估计，不应按小数位数理解为实际精度。
5. 坐标原点是图像左上角，x 向右、y 向下；左右均指主相机画面左右。分位数区间分别沿 x/y 统计，不能当作覆盖90%点的联合二维置信框。
6. 本轮未将历史采集批次强行套用当前标定转换成米制世界坐标，尚未核对历史相机安装和物体高度。未提取完整物体运动轨迹或三维姿态，也未重新评判成功标签。
